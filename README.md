# 烈日战线 · Blazing Frontline

**在线游玩：https://yjj0339.github.io/blazing-frontline/**

明亮卡通风第一人称射击游戏（纯前端 Three.js，零依赖零后端）。整个战场 14 名士兵（你 + 13 名 AI）真实混战：AI 会巡逻、寻路、互相交火、换弹、走位侧移、追击声源——不是站桩靶子。

## 玩法

| 模式 | 说明 |
|---|---|
| 团队死斗 | 蓝队 7 人 vs 红队 7 人，先达 30 杀获胜（6 分钟） |
| 据点争夺 | 占领中央 A 点持续得分，击杀也加分，先达 60 分获胜（8 分钟） |
| 个人混战 | 以一敌七，先达 15 杀获胜（5 分钟） |

敌人强度三档：新兵 / 老兵 / 精英（精英会侧翼包抄）。两张战场可选：

- **烈日镇**：正午强光，草地与集装箱战场
- **戈壁小镇**：斜阳长影，沙色巷道与断墙，东西对峙

## 武器熟练度

每把武器独立练级（击杀 +20 XP、命中 +1 XP），升级**换弹更快、腰射更准**；菜单"军械库"查看四枪进度，结算面板显示本局熟练度收益。

- **武器**：突击步枪 AR-7（AUTO/三连发切换）、霰弹枪 SG-8（8 弹丸）、狙击枪 SR-50（高倍镜 ×3.8 可切 ×7.5）、手枪 P-9，外加手雷（18 秒补一发）；AR 配全息镜、其余机瞄/高倍镜
- **连杀奖励**：3 连杀解锁**侦察机**（按 5，全图敌人暴露 9 秒）；6 连杀解锁**空袭**（按 6，在准星处落下 4 连爆）；9 连杀触发**狂暴**（射速 +60%、弹匣无限 10 秒）
- **爽快手感**：击杀 hitstop 顿帧、连击大字、击杀回血 25、滑铲（冲刺中按蹲）+ 滑跳、开火屏震与枪口火光、AI 士兵受击闪红、会丢手雷、会喊话报点
- **动态战斗音乐**：全合成三档强度——巡逻 / 接战 / 激战自动切换；低血量心跳音
- **成长系统**：跨局经验与军衔（新兵 → 传奇战场之王），菜单 3D 战场背景巡游
- **机制**：后坐力/移动扩散、蹲下更稳、爆头 ×2、不受击 3.2 秒自动回血、重生 2 秒保护
- **环境杀伤**：全场油桶可以打爆（3 发引爆），爆炸连锁殉爆，别站在桶边
- **狙击真实化**：开镜有呼吸晃动，按住 Shift 屏息稳定 4 秒，憋太久喘得更凶
- **声音反馈**：子弹擦身嗖声，命中金属/木头/石头/沙袋音色各不相同
- **小地图**：只有开过枪的敌人才会暴露红点（侦察机期间全部暴露）
- 支持手机触屏（虚拟摇杆 + 视角滑动 + 全按键），横屏体验最佳

## 技术

- Blender 5.2 无头建模：士兵（分件枢轴 + 代码摆动动画）、四套第一人称枪模、全套战场道具 → GLB
- Three.js r170：2.5D 命中判定（AABB 遮挡 + 胶囊命中 + 部位分区）、A* 路点寻路、WebAudio 全合成音效（枪声距离衰减 + 声像）
- 无任何付费素材，全部资产程序生成

## 本地运行

```bash
node tools/server.js 8123
# 打开 http://localhost:8123/
```
